# Changelog — Mantra CLI & Project Manager

All notable changes to the **Mantra CLI & Project Manager** extension will be documented in this file.

Owned & Maintained by [Solotron Technologies Private Limited](http://www.solotrontech.com).

## [0.6.0] - 2026-10-31

### Added
- Official launch of the Mantra CLI VS Code Extension.
- Branding with `mantra_color_logo.png`.
- Formal ownership attributed to Solotron Technologies Private Limited (http://www.solotrontech.com).
- Full Details, Features, and Dependencies documentation tabs.
- Interactive Project Creation wizard (`mantra create`) for Frontend Hybrid (iOS/Android/Web) and Backend (REST/GraphQL).
- Multi-target execution commands for Web, Android, and iOS.
- Production build actions for WASM, APK, AAB, and iOS bundles.
- Code quality integrations: `mantra fmt`, `mantra lint`, and `mantra check`.
- Automated testing and Mobile Bridge security conformance tests.
- Toolchain Diagnostics view in the Mantra sidebar with live status indicators.
- Status bar shortcut for quick access to all CLI actions.
