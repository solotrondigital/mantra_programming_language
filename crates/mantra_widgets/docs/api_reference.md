# Mantra Widgets API Reference

## Component Summary

### 1. Buttons
* `MantraButton`: Base configurable button with primary, secondary, outline, ghost variants.
* `elevated_button(text)`: Button with drop shadow elevation.
* `outlined_button(text)`: Transparent background with distinct border.
* `icon_button(icon)`: Circular icon button.
* `ButtonGroup`: Grouped set of buttons with shared boundaries.

### 2. Cards
* `MantraCard`: Card container with customizable elevation and curvature.
* `StatisticsCard`: KPI summary card with trend percentages.
* `ProductCard`: E-commerce product card with image and pricing.
* `PricingCard`: SaaS tier pricing card with features checklist.

### 3. Avatars & Badges
* `Avatar`: Circular or rounded avatar with image, initials, and presence indicator.
* `Badge`: Pill count or dot status badge.
* `Chip`: Compact interactive tag.

### 4. Navigation
* `AppBar`: Sticky top application bar.
* `BottomNavigationBar`: Persistent mobile bottom tab bar.

### 5. Forms
* `TextField`: Text input with error labels and placeholder.
* `Switch`: iOS/Material style toggle switch.
* `Checkbox`: Square check control.

### 6. Layouts
* `Container`: Spatial box with padding, margin, borders, and colors.
* `Row`: Horizontal flexbox layout.
* `Column`: Vertical flexbox layout.
* `GridView`: Responsive multi-column grid.
* `ListTile`: Common list row item.
* `Divider`: Visual separation line.

### 7. Feedback & Loaders
* `AlertDialog`: Modal alert dialog.
* `Toast`: Floating notification capsule.
* `CircularLoader`: Spinning progress indicator.
* `ProgressBar`: Linear filled progress meter.
* `Shimmer`: Content skeleton animation.
* `StarRating`: 5-star rating display.
* `LikeButton`: Interactive heart button with count.
